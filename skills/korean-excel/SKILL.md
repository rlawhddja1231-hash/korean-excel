# 한국식 엑셀 (.xlsx / .xlsm / .csv)

한국 사무 엑셀에서 자주 나오는 일을 한 번에 한다. 도구 `scripts/kexcel.py` 가 그 일을 한다. 속은 openpyxl(MIT)과 holidays(MIT)다.

근거 등급: **[도구 시험]** 직접 만든 시험 파일과 3,000줄 엉망 자료로 돌려 본 것(2026-10-25) / **[확인]** 실제 사용자 파일로 해 본 것(날짜를 적는다) / **[추정]** 내 짐작.

---

## 0. 말하는 법

- 쉬운 한국어로 말한다. 물을 것은 선택지로 하나씩 묻고, 추천 하나와 이유 한 줄을 붙인다.
- 도구 이름, 명령어, 영어는 사용자에게 말하지 않는다. "엑셀 도구로 검사했어요"처럼 말한다.
- 사용자가 질문하면 되묻지 말고 먼저 답한다.
- **값을 바꾸기 전에는(정리·가리기·중복 지우기) 무엇이 몇 곳 바뀌는지 먼저 보여 주고 묻는다.** `--dry` 로 미리 본다.
- 원본은 건드리지 않고 새 이름(`이름_정리.xlsx`)으로 저장한다. 결과 파일은 전체를 한 번에 준다(SendUserFile).
- **개인정보를 채팅에 그대로 옮겨 적지 않는다.** 도구가 보여 주는 보기 값은 이미 가려져 있다. 원본 값을 말해야 하면 줄 번호로 말한다("7번째 줄 주민번호").

## 1. 할 수 있는 것과 못 하는 것

**할 수 있는 것** [도구 시험]
- **무엇이 든 칸인지 알아보기**: 칸 이름(성명·연락처·주민번호·사업자…)과 값 모양으로 주민등록번호, 사업자등록번호, 전화번호, 이메일, 계좌, 주소, 날짜, 금액, 사람 이름 칸을 알아본다. 맨 위 제목 줄·작성자 줄·빈 줄이 있어도 칸 이름 줄을 찾는다(칸 이름처럼 보이는 낱말이 가장 많은 줄). 주문번호·코드·사번처럼 '번호·코드'가 붙은 칸은 전화·날짜로 잘못 바꾸지 않게 글 칸으로 둔다.
- **검사**: 주민(외국인)등록번호 — 자리 수, 앞 6자리가 있는 날짜인지, 검사 숫자. 사업자등록번호 — 검사 숫자(오타를 거의 다 잡는다). 전화·이메일 모양, 날짜로 읽히는지, 같은 사람이 두 번 있는지. 틀린 칸은 노란색, 확인할 칸은 살구색으로 칠하고 메모를 단다.
  - 2020년 10월 이후 새로 받은 주민번호는 검사 숫자가 없다. 그래서 검사 숫자가 안 맞으면 "틀림"이 아니라 "확인 필요"로만 표시한다.
- **정리**: 날짜(2020. 3. 2. / 2021년 5월 17일 / 21.11.01 / 20220104 / 2020/03/02 / 2024.1.2 오후 3:15 / 엑셀 날짜 숫자) → 진짜 엑셀 날짜. 전화(01012345678 / 02 345 6789 / +82 10-… / 010.4444.5555 / 앞 0이 빠진 숫자 1098765432) → 010-1234-5678. 사업자번호 → 123-45-67890. 금액(3,200,000원 / ₩2,800,000 / 320만원 / 1억 2천만원 / 삼백만원 / (100,000)=마이너스) → 계산되는 숫자(천 단위 쉼표 모양). 띄어쓰기·전각 글자 정리. 바뀐 칸이 ###로 안 보이게 열 너비를 넓힌다. 글자 모양·색·합친 칸·계산식은 그대로 둔다.
- **개인정보 가리기**: 주민번호 뒤 6자리, 전화 가운데, 이메일 앞부분, 계좌 가운데, 이름 가운데(홍●동)를 ●로. 칸 이름 줄 위의 제목·작성자 줄, 숨긴 시트, 셀 메모까지 본다. 이름 칸에 있던 이름은 다른 시트의 글 속에서도 가린다. 글 속에 섞인 주민번호(하이픈 없어도), 전화(+82, 050, 1588 같은 대표번호 포함), 이메일, 계좌(하이픈 있는 것, 또는 은행 이름 옆 숫자)도 찾는다. 숫자로 저장된 주민번호, 모양이 틀린 번호도 가운데를 가린다. 사업자번호·날짜·금액은 가리지 않는다.
- **주소 나누기**: 시도(서울→서울특별시처럼 정식 이름으로), 시군구(성남시 분당구처럼 두 단어도), 읍면동·도로명, 나머지, 도로명/지번 구분, 앞에 붙은 우편번호. 광주광역시와 경기도 광주시를 구분한다.
- **만 나이·성별**: 주민번호나 생년월일(여러 모양, 900101 같은 6자리도)로 생년월일·만 나이(기준일 지정 가능)·성별 칸을 더한다.
- **영업일**: 두 날짜 사이 영업일 수(주말·공휴일·대체공휴일 빼고, 양 끝 포함), N 영업일 뒤 날짜, 줄마다 영업일 수 칸, 그해 공휴일 목록. 임시공휴일은 `--extra` 로 더한다. 토요일 근무면 `--sat`.
- **한글 금액**: 1234500 → 일금 일백이십삼만사천오백원정(위조 막기용으로 '일'을 다 적음), `--plain` 이면 백이십삼만사천오백 원. 칸 하나 통째로도.
- **합치기·나누기·중복**: 여러 파일·시트를 칸 이름에 맞춰 한 표로(출처 칸 붙임, `--same 성명=이름` 으로 이름이 다른 같은 칸 합치기, '합계·소계' 줄은 빼고, 계산식 칸은 엑셀이 저장해 둔 결과 값으로 옮김). 칸 값마다 시트나 파일로 나누기. 고른 칸이 같은 줄을 색으로 표시하거나 지우기(전화·주민번호는 모양이 달라도 숫자가 같으면 같은 것으로 본다).
- **CSV 저장**: 관공서·은행 업로드용 CP949(EUC-KR) 또는 UTF-8. CSV를 열 때 글자가 깨지는 문제(CP949/UTF-8)를 알아서 맞춰 읽는다.

**못 하는 것**
- 옛날 .xls 파일 — 엑셀에서 .xlsx로 다시 저장한 파일이 필요하다고 말한다.
- 암호 걸린 파일.
- 계산식을 다시 계산하는 것 — 계산식 칸은 고치지 않고, CSV로 바꿀 때는 엑셀이 저장해 둔 결과를 쓴다. 엑셀에서 한 번도 안 연 파일은 그 값이 비어 있다(도구가 알려 준다).
- 그림 속 글자, 시트 이름, 계산식 칸, 파일 정보(작성자)는 가리지 못한다. 별명·이니셜처럼 이름 칸에 없는 이름도 못 찾는다(`--words` 로 알려 주면 가린다).
- 합친 칸이 있는 표에서는 중복 줄을 지우지 않고 색 표시만 한다(줄을 지우면 표가 틀어지므로).
- 주민번호·사업자번호가 **실제로 있는 번호인지**는 모른다. 모양과 검사 숫자만 본다. 사업자 휴·폐업 조회는 국세청 홈택스에서 해야 한다.
- 4대 보험·세금 계산은 하지 않는다. 요율이 해마다 바뀌어서 틀릴 위험이 크다. 필요하면 사용자가 준 요율로 내가 직접 계산하고 "요율은 올해 공식 고시로 확인하세요"라고 말한다.
- 엑셀 차트·피벗 표 만들기는 이 도구가 아니라 일반 엑셀 작업으로 한다.

## 2. 일하는 순서

1. **준비** (채팅마다 한 번)
   ```
   pip install -q --break-system-packages openpyxl holidays
   K=$(find / -name kexcel.py -path '*korean-excel*' 2>/dev/null | head -1); echo $K
   ```
2. **파일 받기**: 채팅에 올린 파일, 또는 연결된 PC 폴더의 파일. 원본은 작업 폴더에 복사해서 쓴다.
3. **먼저 본다** — 무엇이든 하기 전에:
   ```
   python3 $K info 명단.xlsx
   ```
   시트, 칸 이름 줄, 칸마다 무엇이 든 칸인지가 나온다. 칸 이름 줄을 잘못 잡았으면 `--header 3` 처럼 알려 준다. 사용자에게 "직원 명단이고 8명, 주민번호·연락처·입사일·월급 칸이 있어요"처럼 한두 줄로 말한다.
4. **할 일에 맞는 명령**

   | 사용자 말 | 명령 |
   |---|---|
   | "틀린 데 없나 봐 줘 / 주민번호 맞아?" | `check 명단.xlsx` (칸을 정하려면 `--cols 주민번호,연락처`) |
   | "날짜·전화번호 통일해 줘 / 정리해 줘" | 먼저 `clean 명단.xlsx --dry` 로 보여 주고 묻는다 → `clean 명단.xlsx` (일부만: `--what date,phone`) |
   | "개인정보 가려 줘 / 마스킹" | 먼저 `mask 명단.xlsx --dry` → `mask 명단.xlsx` (이름은 그대로 두려면 `--keep-names`, 이름 칸이 없으면 `--words 홍길동,김철수`) |
   | "주소 시도별로 나눠 줘" | `addr 명단.xlsx` (주소 칸을 못 찾으면 `--col 주소`) |
   | "만 나이 / 몇 살인지" | `age 명단.xlsx [--on 2026-12-31]` |
   | "10월 영업일 며칠?" | `workdays 2026-10-01 2026-10-31` |
   | "오늘부터 10 영업일 뒤" | `workdays 2026-10-25 --add 10` |
   | "과제마다 영업일 수" | `workdays 일정.xlsx --start 시작일 --end 종료일` |
   | "올해 공휴일" | `holidays 2026` |
   | "한글 금액으로 / 일금 …원정" | `money 1234500` 또는 `money 견적.xlsx --col 금액` |
   | "이 파일들 하나로 합쳐 줘" | `combine a.xlsx b.xlsx c.csv --out 합본.xlsx` (이름 다른 같은 칸: `--same 성명=이름,연락처=휴대폰`) |
   | "부서별로 나눠 줘" | `split 명단.xlsx --by 부서` (시트로) / `--files` (파일로) |
   | "중복 찾아 줘 / 지워 줘" | `dupes 명단.xlsx --cols 이름,연락처` (표시) → 묻고 → `--remove` |
   | "은행 업로드용 CSV / 깨지지 않게" | `tocsv 명단.xlsx --encoding cp949` |

   공통: `--sheet 시트이름`(안 주면 첫 시트, info·mask는 모든 시트), `--out 저장할곳`, `--show 30`(보여 줄 줄 수).

5. **결과를 직접 본다.** 도구가 알려 준 "못 바꾼 칸"을 사용자에게 줄 번호로 알린다. 중요한 파일은 LibreOffice가 있으면 PDF로 바꿔 쪽 그림으로 확인한다(`soffice --headless --convert-to pdf`).
6. **결과 주기**: 새 파일을 SendUserFile로 준다. 한 줄로 "날짜 7곳, 전화 5곳을 정리했고, 6번째 줄 이메일은 모양이 틀려서 그대로 뒀어요"처럼.

## 3. 조심할 것

- **정리는 값을 바꾼다.** 날짜·금액을 진짜 날짜·숫자로 바꾸면 그 칸을 글자로 쓰던 다른 프로그램이 달라질 수 있다. 처음엔 `--dry` 로 보여 준다.
- 두 자리 연도(21.11.01)는 올해보다 1년 뒤까지는 2000년대, 그 밖은 1900년대로 읽는다. 생년월일 칸이면 결과를 한 번 훑는다.
- 중복 지우기는 처음 나온 줄을 남기고 뒤에 나온 줄을 지운다. 지우기 전에 반드시 표시본을 먼저 보여 준다. 계산식이 있는 시트면 범위가 어긋날 수 있다고 알린다.
- 가린 파일도 셀 메모·숨긴 시트·그림까지 깨끗한지는 사용자에게 한 번 더 확인하라고 말한다.
- 공휴일은 holidays 라이브러리 기준이다. 나라에서 새로 정한 임시공휴일은 늦게 들어갈 수 있다.
