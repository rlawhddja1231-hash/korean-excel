# 한국식 엑셀 — 시험 기록

## 2026-10-25 처음 만듦 [도구 시험]

시험 파일: 일부러 엉망으로 만든 직원 명단(맨 위 제목 줄 + 합친 칸 + 빈 줄 + 노란 머리줄 + 합계 계산식, 7명), 메모 시트(글 속 전화·계좌·주민번호·이메일), CP949 CSV 명단, 일정표, 3,000줄 무작위 자료.

- 칸 알아보기: 제목 줄·빈 줄을 건너뛰고 3번째 줄을 칸 이름 줄로 찾음. 10칸 모두 맞게 알아봄.
  - 고친 것: "사업자등록번호" 칸이 '등록번호' 때문에 주민번호로 잡혔다 → 사업자를 먼저 보게 함.
- 검사: 12자리 주민번호(틀림), 2001년생 검사 숫자 불일치(확인 필요), 같은 사람 두 번(확인 필요), `lee@@example`(틀림), 앞 0 빠진 전화(확인 필요), 사업자번호 검사 숫자 틀림을 모두 잡음.
  - 고친 것: 합계 계산식 칸을 "금액으로 못 읽음"이라고 했다 → 계산식 칸은 건너뜀. 같은 거래처 사업자번호가 여러 줄에 있는 건 정상이라 중복 표시에서 뺌.
- 정리: 날짜 7가지 모양, 전화 5가지 모양, 금액 6가지 모양(1억 2천만원, 삼백만원, (100,000) 포함) 모두 바꿈. 계산식·머리줄 색·합친 칸 그대로.
  - 고친 것: 날짜로 바꾼 칸이 좁아서 ###로 보였다(LibreOffice로 열어 봄) → 바뀐 칸 너비를 넓힘. 900101 같은 6자리 생년월일도 읽게 함.
- 가리기: 이름·주민·전화·이메일 칸과 메모 글 속 개인정보.
  - 고친 것: 사업자번호가 계좌로 잘못 가려졌다 → 검사 숫자가 맞는 사업자번호와 날짜·금액 칸은 안 가림. 자리 수가 틀린 주민번호도 가림. 이름 칸의 이름을 다른 시트 글 속에서도 가림.
- 주소: 서울/경기 성남시 분당구/우편번호 붙은 안성 금광면 금광리(지번)/부산 우동/광주 광산구/세종 모두 맞게 나눔.
- 만 나이: 2026-10-25 기준 1990-01-01생 36세, 2001-12-31생 24세 맞음.
- 영업일: 2026년 10월 = 20일(개천절 대체 휴일 10-05, 한글날 10-09 뺌) 맞음. 10-25(일)에서 10 영업일 뒤 = 11-06(금) 맞음.
- 합치기: CSV(CP949)+엑셀, 계산식 칸은 비움(옮기면 범위가 틀어지므로 — 아래 검사 뒤 '저장된 결과 값'으로 바꿈). `--same 성명=이름` 으로 다른 이름 칸 합침.
- 3,000줄 무작위 자료로 모든 명령 돌림 — 멈춘 곳 없음.

## 2026-10-25 다른 검사 담당의 시험 [도구 시험]

만든 사람이 아닌 검사 담당이 까다로운 파일을 직접 만들어 넣어 봄. 찾은 것과 고친 것:
- 가리기: 칸 이름 줄을 작성자 줄로 잘못 잡아 거의 다 안 가려졌다 → 칸 이름 낱말이 가장 많은 줄을 칸 이름 줄로. 칸 이름 줄 위(제목·작성자 줄)·셀 메모도 가림. `--header` 가 모든 시트에 걸려 숨긴 시트가 빠졌다 → 고른 시트에만.
- 가리기: 하이픈 없는 주민번호, 숫자로 저장된 주민번호, +82·050·1588 번호, 은행 이름 옆 하이픈 없는 계좌, 모양이 틀린 번호·이메일 → 모두 가림. '합계'·'메모'를 이름으로 가리던 것 고침.
- 전화 칸의 "김철수 010 7777 8888" 이 번호만 남고 글이 지워졌다 → 숫자·하이픈 말고 다른 글자가 있으면 전화번호 값으로 보지 않고 글 속 번호만 가림.
- 주문번호(10자리 숫자)가 전화번호로, 코드 "200101"이 날짜로 바뀌었다 → '번호·코드' 칸은 글 칸, 6자리 날짜는 날짜 칸에서만.
- 정리·검사 화면에 원래 번호가 그대로 보였다 → 보여 주는 값은 모두 가린 모양.
- 05012345678 → 050-1234-5678. CSV의 여러 줄 칸이 붙어 버렸다 → 그대로 둠.
- 나누기: A/B와 A_B가 같은 파일 이름으로 덮였다, abc/ABC·History 시트 이름 → 번호 붙임. 중복 지우기에서 합친 칸이 어긋났다 → 합친 칸이 있으면 표시만.
- 합치기: '합계' 줄이 남았다 → 뺌. 계산식 칸은 저장된 결과 값으로.
- 검사: 엑셀 날짜 숫자(45000)를 틀림으로 칠했다 → 확인 필요. 원래 셀 메모를 덮었다 → 이어 붙임.
- 멈춤 4곳(없는 날짜, 연도 아닌 글, 아주 큰 금액, 틀린 기준일) → 쉬운 말로 알림. 1,000.50원의 원 아래를 말없이 버리던 것 → 알림. 270315 생년월일을 2027년으로 읽던 것 → 1927년.
